分組 ID 和分支 ID 使用 1–40 個英文字母、數字、`_` 或 `-`。分組與分支都屬於本條回答的命名空間。全介面同一時間只啟用一個分組，再點同一個開關關閉高亮；未分組選點不受分組影響。`branch` 與 `turn` 不能同時出現，`ply` 只與 `branch` 搭配，省略時為 0。`turn=0` 為原局初始局面。坐標使用 GTP（跳過 I），超出當前棋盤的坐標不高亮，空標籤自動顯示坐標。

標記只作用於 Agent 正文。文字須處於對話滾動區域的可視範圍，棋盤也須處於該消息或開關定位的局面；工具記錄、使用者提問、折疊面板不產生標記。滑鼠越接近文字或對應棋盤點，高亮越深；懸浮任一端或鍵盤聚焦文字會顯示半透明虛線貝塞爾曲線，從棋盤標記右上緣連接到可見文字左上角，兩端控制點分別水平向右、向左延伸。重復坐標共用棋盤標記，滑鼠較近的可見文字決定亮度和連線。

## Agent 編輯試下

`edit_trial` 在服務端調用 `shared/` 規則驗證整條手順，成功後通過工具事件保存到當前回答的 `trials`，並隨對話持久化。失敗保留已有分支。創建分支不會自動切換棋盤，也不會修改實戰棋譜；使用者點擊 selector 後才打開，可用現有時間軸回看、繼續手動試下或另存為新棋局。關閉開關只關閉高亮，保留棋盤位置。

```json
{"id":"line-a","base":"current","moves":["C2","B2"]}
{"id":"line-b","base":"branch","source":"line-a","ply":1,"moves":["B3"]}
```

- `base=current`：從使用者當前局面開始，包含已顯示的使用者試下。
- `base=main` 與 `turn`：從原局某手之後開始。
- `base=branch` 與 `source`：從本輪已有分支開始。`ply` 保留前幾手，`moves` 替換剩餘後續；省略 `ply` 則追加。使用相同 `id` 修改原分支，不同 `id` 建立另一條變化。`moves=[]` 可截斷。
- `operation=delete` 與 `id`：刪除本輪分支；已輸出的舊 selector 會提示分支不存在。

跨輪編輯可先選擇已有分支並定位到需要的手數，再提問；新一輪通過 `current` 繼續。工具的 `source` 僅查本輪已創建的分支，不跨對話隱式查找同名 ID。分支記錄包含起始棋盤和原局起點，用於還原使用者試下前綴；原局已改變而不再匹配時拒絕跳轉。

合法手順不代表引擎推薦，戰術判斷仍需真實棋盤或引擎證據。運行時教練規範的唯一來源為 [prompts/coach.zh-CN.md](../../prompts/coach.zh-CN.md)。
