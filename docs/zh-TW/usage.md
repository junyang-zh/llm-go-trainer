## 安裝與首次啟動

從 [GitHub Releases](https://github.com/junyang-zh/llm-go-trainer/releases) 下載對應平台的安裝包：Windows 10/11 x64 使用 `.exe`，macOS 15+ Apple Silicon 使用 `.dmg`。Windows 運行安裝器；macOS 將應用拖入 Applications。首次安裝無需下載供自動更新使用的 `.zip` / `.yml`，GitHub 的 Source code 是源碼，不是安裝包。

普通版內建引擎、依賴、主模型與 HumanSL，支援離線準備這些資源；`minimal` 版不自動下載，請按右上角提示前往左上角「設定 → 圍棋模型」，點擊「下載並啟用 KataGo」，兩種版本功能相同。Windows 普通版內建 OpenCL 引擎，仍需顯卡 OpenCL 驅動；macOS 內建 Metal 引擎及動態函式庫，無需安裝 Homebrew。macOS 發佈憑據齊全時提供 Developer ID 簽名與 Apple 公證，否則提供未簽名、未公證的安裝包；Windows 安裝器尚未設定代碼簽名。

普通版首次啟動、minimal 版手動啟用後，會在後台準備引擎、模型並初始化 GPU，在「設定 → 圍棋模型」查看進度；期間可以落子、導入 SGF 和復盤。引擎就緒後啟用分析和對戰，後續啟動復用已校驗的快取。模型選擇、下載重試和計算後端見[引擎與模型](engines.md)。

在「設定 → 連接 LLM」選擇並設定 AI 教練服務，模型與思考深度會保存供後續使用。具體步驟見 [LLM 設定](llm.md)。從源碼運行見[開發指南](development.md)。

## 語言設定

在「設定 → 通用 → 語言」選擇英文、簡體中文、繁體中文、日語或韓語。預設跟隨系統語言，不支援的系統語言回退到英文；手動選擇保存在本機並立即生效，不重置棋盤、對話或草稿。已知引擎通知、模型狀態與錯誤隨語言切換；使用者命名、棋譜、手動輸入的模型名與未知供應商診斷保留原文。語言設定只影響介面，運行時教練提示詞仍為中文，不會自動改變生成回答的語言。

## 當前功能

| 功能     | 支援情況                                                                        |
| -------- | ------------------------------------------------------------------------------- |
| 棋盤     | 9 / 13 / 19 路；提子、自殺禁著、劫；自由復盤、停一手、主線導航                  |
| 人機對戰 | KataGo JSONL；可執黑/白；0 或 2–9 子讓子；自訂貼目                              |
| 難度     | HumanSL 等級採樣；無模型時回退到限制目損的隨機選點；最強模式                    |
| 棋風     | 隨機度、目損上限；近似激進度 = 接觸戰偏好，限隨機模式                           |
| 分析     | 按手數顯示黑方勝率/目差曲線、候選開關、PV 試讀、歸屬預測                        |
| 數目     | 中國規則手動標記死子後的面積預覽，含讓子還點                                    |
| 棋譜     | 野狐/星陣導出的標準 SGF；UTF-8 / GB18030；根擺子與主線；SGF 導出                |
| 教練     | Markdown 流式對話、工具搜索與執行記錄；解釋選點、局勢和變化；停止分析、導出證據 |
| LLM      | DeepSeek API、Codex CLI、Claude Code CLI 適配器                                 |
| 桌面     | Electron；GitHub Release 更新；macOS 可選簽名及公證，Windows NSIS 安裝器        |

匯入 SGF 時，一個檔案儲存為一個歷史棋譜條目；棋譜集、全部變化、原註釋及圖形標記完整保留。開啟條目可瀏覽變化、返回上層，並將所選局面開啟到主棋盤。匯入不設檔案大小、節點數或分支深度限制。中途擺子、清除棋子和修改行棋方按原圖處理；非法手順顯示錯誤，原譜仍完整保留。日本規則可以對戰與引擎分析，正式終局數目尚未實現。HumanSL 等級不等於野狐/星陣認證等級。當前沒有平台賬號直連、整局自動批量講解、讀秒、認輸、持久化分析快取。

模型庫、Windows OpenCL / CUDA 切換和按次數 / 時間限制搜索見[引擎與模型](engines.md)。

## 棋局歷史、試下與對話

棋局自動保存到本機歷史庫，在「歷史棋局」中選擇棋局或導入/導出 SGF。桌面應用預設使用 Electron 的 `userData/history`，Web 模式使用 `.local/history`；可用 `GO_TRAINER_HISTORY_DIR` 指定其他可寫目錄。資料庫為按記錄原子寫入的 JSON 文檔庫，無需額外安裝資料庫，也不寫入應用安裝包。使用系統臨時目錄時，資料可能被系統清理。

主頁使用「AI 自動落子」開關，並可直接選擇「AI 執白 / AI 執黑」。關閉時雙方均可手動落子，開啟時 AI 自動走所選顏色。主線末尾落子進入實戰記錄；在歷史手數落子（包括 AI 落子與停一手）進入試下分支，原主線不變，試下棋子以手數編號標識。存在試下時顯示「清空試下」和「保存試下為新棋局」。歷史局面下還可點擊「分支新棋局」，保留原局並把當前局面另存；後續落子進入新局主線。時間軸可在當前試下中回看；離開當前試下範圍或切換棋局會結束當前未保存的試下，已保存的教練分支可從對話重新打開。試下局面可直接請求分析與教練講解。

對話獨立於棋局：切換棋局、手數、導入或新建棋局均保留當前對話與草稿。「新對話」創建獨立會話，「歷史對話」恢復已保存會話。每輪記錄提問時的棋局 ID、原局手數、時間與試下手順；失敗或停止的分析也保留記錄。應用重啟後，未完成的分析標記為已中斷。

教練通過 `query_game_history` 查詢歷史棋局列表，或按 `gameId` 與 `turn` 讀取棋譜和局面；當前上下文還包含使用者試下手順。棋局歷史查詢不依賴當前對話，也不會修改棋譜。

## 介面與流式分析

主介面按窗口寬高佈局，棋盤自動適配剩餘空間；頁面本身不滾動，對話和設定各自滾動。左上角 logo是統一設定入口，包含「通用」「圍棋模型」「AI 自動落子」和「連接 LLM」四頁；LLM 和圍棋引擎狀態在對話區頂部並排顯示。

右側常駐「目差 / 勝率」面板，預設收起，展開後顯示兩條按手數排列的曲線。引擎就緒後自動分析當前局面，每次使用 `min(训练 visits, 100)`；人機對戰復用對手搜索結果。導入棋譜後可點擊「補全曲線」依次分析缺失手數，也可隨時停止。後台曲線查詢使用圍棋引擎，前台分析和 AI 落子優先。

曲線的勝率和目差均為黑方視角：正目差表示黑方領先，負值表示白方領先，屬於引擎估計。未分析手數保留空缺，未完成搜索用空心點標記；點擊曲線上的點可跳到對應手數。回退復盤保留當前主線的歷史資料；更換棋譜、規則/貼目或引擎時隔離舊結果。曲線資料僅在本次運行中保留，較深的已完成搜索不會被後台低 visits 結果覆蓋。

展開時當前數值位於面板標題右側，折疊時隱藏；搜索次數與次數/秒放在已分析進度處。計算期間預留曲線與候選後續空間，結果出現時不會推動面板與棋盤。棋盤下方「候選點」控制棋盤 A/B/C 標記，展開面板內保留獨立候選列表。聊天支援 Markdown 標題、列表、強調、表格、引用和代碼塊；長表格和代碼塊單獨滾動。網頁連結由系統瀏覽器打開。

分析時先顯示 KataGo 搜索量、黑方勝率/目差與主要變化，再顯示 LLM 回答。DeepSeek 和 Claude Code 支援增量正文；Codex 的更新粒度取決於 CLI 版本，部分版本在完整消息生成後才返回正文。

教練可主動檢查棋塊與氣，試下指定手順並調用引擎搜索後續應對。例如提問“這塊白棋是否安定”，它可以比較攻擊、防守或脫先的變化。對話內顯示每次工具執行的狀態，展開可查看試下手順、目差和主變化；點擊“停止”會取消正在執行的搜索與模型請求。試下結果保存在本次講解記錄中，實戰棋譜保持原樣。

點擊“停止”或關閉請求會取消對應 KataGo 查詢 / LLM 請求 / CLI 子程序。中斷時保留已收到的內容，並標記未完成；只有完成的講解進入後續對話上下文。

## 應用更新

在「設定 → 通用」查看當前版本、檢查 GitHub Release 或開啟「自動更新」。自動更新預設關閉；開啟後在啟動時及每 4 小時檢查穩定版。下載後點擊「重啟並安裝」，應用先保存本地記錄並關閉引擎，再安裝更新；不會在對局或分析期間自動重啟。

已快取校驗通過的模型時，更新使用不含模型和引擎歸檔的 minimal 安裝包，繼續復用已有模型、後端和調優快取；未快取有效模型的普通版仍使用普通版安裝包。更新通道和校驗機制見[構建與發佈](releases.md#updates)。

自動安裝適用於桌面安裝版。macOS 需要 Developer ID 簽名版本，源碼運行和瀏覽器模式不安裝更新；未簽名 macOS 包會顯示說明及 GitHub Release 入口。
