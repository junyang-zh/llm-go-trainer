## 설치와 첫 실행

[GitHub Releases](https://github.com/junyang-zh/llm-go-trainer/releases)에서 Windows 10/11 x64는 `.exe`, macOS 15+ Apple Silicon은 `.dmg`를 선택하세요. Windows는 설치 파일을 실행하고 macOS는 앱을 Applications로 끌어 놓습니다. `.zip` / `.yml`은 자동 업데이트용입니다. Source code는 소스 코드이며 설치 파일이 아닙니다.

일반판에는 엔진·의존 파일·주 모델·HumanSL이 포함되어 오프라인으로 준비할 수 있습니다. `minimal`은 첫 실행 때 다운로드하며 기능은 동일합니다. Windows 일반판은 OpenCL 엔진을 포함하지만 GPU의 OpenCL 드라이버는 필요합니다. macOS는 Metal과 라이브러리를 포함하므로 Homebrew가 필요 없습니다. macOS 배포 인증 정보가 모두 있으면 Developer ID 서명과 Apple 공증을 하고, 없으면 서명·공증 없이 배포합니다. Windows 코드 서명은 아직 설정하지 않았습니다.

엔진·모델 준비와 GPU 초기화는 백그라운드에서 진행됩니다. **설정 → 바둑 모델**에서 상태를 확인하며, 그동안 착수·SGF 가져오기·복기를 할 수 있습니다. 준비가 끝나면 분석과 AI 대국을 사용할 수 있고 이후에는 검증된 캐시를 재사용합니다. 모델 선택, 재시도, 백엔드는 [엔진과 모델](engines.md)을 참고하세요.

**설정 → LLM 연결**에서 코치를 설정합니다. 모델과 추론 수준은 다음 요청에 사용할 수 있도록 저장됩니다. [LLM 설정](llm.md), 소스 실행은 [개발 안내](development.md)를 참고하세요.

## 언어

**설정 → 일반 → 언어**에서 영어, 중국어 간체·번체, 일본어, 한국어를 선택합니다. 기본값은 시스템 언어이며 지원하지 않는 언어는 영어로 표시합니다. 선택은 로컬에 저장되고 바둑판·대화·초안을 초기화하지 않고 즉시 적용됩니다. 알려진 엔진 알림, 모델 상태, 오류도 언어를 따릅니다. 사용자 이름, 기보, 직접 입력한 모델명, 알 수 없는 공급자 진단은 원문을 유지합니다. 이 설정은 UI만 번역하며 중국어 실행 코치 프롬프트나 생성 답변의 언어를 자동 변경하지 않습니다.

## 현재 기능

| 항목     | 지원 내용                                                                   |
| -------- | --------------------------------------------------------------------------- |
| 바둑판   | 9·13·19줄, 따내기, 자살수 금지, 패, 자유 복기, 한 수 쉼, 본보 이동          |
| AI 대국  | KataGo JSONL, 흑·백 선택, 접바둑 없음 또는 2–9점, 덤 설정                   |
| 난이도   | HumanSL 급단 샘플링, 없으면 손실 집 수 제한 무작위 선택, 최강 모드          |
| 기풍     | 무작위성·손실 상한, 공격성은 접촉전 선호의 근사치이며 무작위 모드에만 적용  |
| 분석     | 흑 승률·집 차이 그래프, 후보 수, 주요 변화도 미리 보기, 영역 예측           |
| 계가     | 사석 수동 표시 후 중국식 면적 미리 보기, 접바둑 보정 포함                   |
| 기보     | 야호·절예에서 내보낸 표준 SGF, UTF-8 / GB18030, 초기 배치·본보, SGF 출력    |
| 코치     | Markdown 스트리밍, 도구 탐색·기록, 착수·국면·변화 해설, 중지, 근거 내보내기 |
| LLM      | DeepSeek API, Codex CLI, Claude Code CLI                                    |
| 데스크톱 | Electron, GitHub Release 업데이트, 선택적 macOS 서명·공증, Windows NSIS     |

SGF는 첫 본보만 가져오고 기존 주석·분기는 훈련 기록에 저장하지 않습니다. 중간 돌 배치·차례 변경은 명시적으로 거부합니다. 일본 규칙으로 대국·분석은 가능하지만 정식 종국 계가는 미구현입니다. HumanSL 급단은 야호·절예의 공인 급단이 아닙니다. 플랫폼 계정 연동, 전 기보 자동 LLM 해설, 초읽기, 불계 선언, 영구 분석 캐시는 아직 없습니다.

모델 목록, Windows OpenCL/CUDA 전환, 탐색 횟수·시간 제한은 [엔진과 모델](engines.md)을 참고하세요.

## 대국 기록, 시험 진행, 대화

대국은 로컬 기록에 자동 저장됩니다. **대국 기록**에서 선택하고 SGF를 입출력합니다. 데스크톱은 `userData/history`, Web은 `.local/history`를 사용하며 `GO_TRAINER_HISTORY_DIR`로 쓰기 가능한 경로를 지정할 수 있습니다. 레코드별 원자적 JSON 저장이므로 DB 설치가 필요 없고 앱 패키지에 기록하지 않습니다. 시스템 임시 폴더는 OS가 지울 수 있습니다.

**AI 자동 착수**와 **AI가 백 / 흑**을 선택합니다. 끄면 양쪽 모두 수동으로 둘 수 있습니다. 본보 끝의 착수는 실전 기록에 추가하고, 과거 국면의 착수·AI 착수·쉼은 본보를 유지한 채 시험 진행 분기를 만듭니다. 시험 진행 돌에는 수 번호를 표시하며 지우거나 새 대국으로 저장할 수 있습니다. **새 대국으로 분기**는 과거 국면을 별도 저장하고 이후 착수를 새 본보에 추가합니다. 시간축으로 시험 진행을 돌아볼 수 있으며 범위를 벗어나거나 대국을 바꾸면 저장하지 않은 시험 진행은 끝납니다. 저장된 코치 분기는 대화에서 다시 열 수 있습니다. 시험 진행에도 분석·해설을 요청할 수 있습니다.

대화는 대국과 독립적입니다. 대국·수 이동, 가져오기, 새 대국도 현재 대화와 초안을 유지합니다. **새 대화**는 별도 세션을 만들고 **대화 기록**에서 복원합니다. 매 요청에 대국 ID, 원래 수 번호, 시간, 시험 진행 순서를 저장하며 실패·중지도 남깁니다. 재시작하면 미완료 분석은 중단됨으로 표시합니다.

코치는 `query_game_history`로 대국 목록이나 `gameId`·`turn`에 해당하는 기보·국면을 읽습니다. 현재 문맥에는 사용자 시험 진행도 포함합니다. 조회는 현재 대화와 독립적이며 기보를 변경하지 않습니다.

## 화면과 스트리밍

바둑판은 남는 화면 공간에 맞춥니다. 전체 페이지는 스크롤하지 않고 대화와 설정만 각각 스크롤합니다. 왼쪽 위 로고에서 일반, 바둑 모델, AI 자동 착수, LLM 연결 탭을 엽니다. LLM과 엔진 상태는 대화 위에 나란히 표시됩니다.

**집 차이 / 승률** 패널은 항상 있으며 처음에는 접혀 있습니다. 펼치면 수별 두 그래프를 표시합니다. 엔진이 준비되면 `min(훈련 visits, 100)`으로 현재 국면을 자동 분석하고 AI 대국에서는 상대 탐색을 재사용합니다. **그래프 완성**은 빠진 수를 순차 분석하며 중지할 수 있습니다. 전면 분석·AI 착수를 우선합니다.

모든 수치는 흑 기준입니다. 양수 집 차이는 흑, 음수는 백 우세이며 엔진 추정값입니다. 미분석 수는 빈칸, 미완료 탐색은 빈 원으로 표시합니다. 점을 누르면 해당 수로 이동합니다. 본보 복기는 결과를 유지하고 기보·규칙·덤·엔진이 바뀌면 이전 결과를 분리합니다. 그래프는 현재 실행 동안만 유지하며 얕은 검색이 완료된 깊은 결과를 덮어쓰지 않습니다.

현재 값은 펼친 제목 오른쪽에 나타나고 접으면 숨깁니다. 탐색 수와 수/초는 분석 진행률 영역에 둡니다. 계산 중에도 그래프·후보 후속 수 공간을 확보해 결과가 나타날 때 패널과 바둑판이 움직이지 않습니다. **후보 수**는 바둑판 A/B/C 표시를 제어하고 펼친 패널에는 별도 후보 목록이 있습니다.

대화는 Markdown 제목·목록·강조·표·인용·코드를 지원합니다. 넓은 표·코드는 따로 스크롤하며 외부 링크는 시스템 브라우저에서 엽니다. 먼저 엔진 탐색량·흑 승률·집 차이·주요 변화도를 보여 준 뒤 LLM 답변이 나옵니다. DeepSeek와 Claude Code는 점진적 본문을 지원합니다. Codex는 CLI 버전에 따라 전체 메시지가 완성된 뒤 본문이 올 수 있습니다.

코치는 돌 무리·활로를 확인하고 수순을 시험하며 응수를 탐색합니다. 예를 들어 백돌의 안정 여부에 공격·방어·손빼기 변화를 비교할 수 있습니다. 도구 기록을 펼치면 수순·집 차이·주요 변화도를 봅니다. **중지** 또는 연결 종료는 해당 KataGo 요청, LLM 요청, CLI 자식 프로세스를 취소합니다. 받은 내용은 미완료 표시로 남고 완료 해설만 후속 문맥에 들어갑니다. 시험 진행은 해당 해설에 저장되고 실전 기보는 그대로입니다.

## 앱 업데이트

**설정 → 일반**에서 버전, GitHub Release 확인, 자동 업데이트를 설정합니다. 기본은 꺼짐이며 켜면 시작 시와 4시간마다 안정판을 확인합니다. 다운로드 후 **다시 시작하고 설치**를 누르면 기록을 저장하고 엔진을 종료한 뒤 설치합니다. 대국·분석 중 자동 재시작하지 않습니다.

검증된 모델 캐시가 있으면 모델·엔진 아카이브 없는 minimal 업데이트를 사용해 모델·백엔드·튜닝 캐시를 재사용합니다. 유효 모델이 없는 일반판은 일반판으로 업데이트합니다. 채널과 검증은 [빌드와 배포](releases.md#updates)를 참고하세요.

자동 설치는 설치된 데스크톱 앱만 지원하며 macOS는 Developer ID 서명이 필요합니다. 소스·브라우저 실행에서는 설치하지 않습니다. 미서명 macOS에는 설명과 수동 설치용 Release 링크가 표시됩니다.
