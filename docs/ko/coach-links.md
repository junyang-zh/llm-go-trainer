# 대화형 해설과 시험 진행 분기

[English](../en/coach-links.md) · [简体中文](../coach-links.md) · [繁體中文](../zh-TW/coach-links.md) · [日本語](../ja/coach-links.md) · [한국어](coach-links.md)

좌표 확장은 표준 Markdown fragment 링크로, 문단·목록·표·인용·참조 링크에서 동작합니다. 코드 블록과 인라인 코드는 원문을 유지하며 HTML이나 `---#block…` 구분자는 사용하지 않습니다. 웹 링크는 외부 링크로, 알 수 없는 fragment는 일반 텍스트로 처리합니다.

| 용도           | 예                                                |
| -------------- | ------------------------------------------------- |
| 그룹 없는 좌표 | `[2선 기기](#C2)`                                 |
| 그룹 좌표      | `[단수](#go/point/B3?group=one)`                  |
| 배타적 선택기  | `[변화 보기](#go/selector/one)`                   |
| 시험 시작 위치 | `[변화 1](#go/selector/one?branch=line-a&ply=0)`  |
| 시험 2수 뒤    | `[후속 수](#go/selector/two?branch=line-a&ply=2)` |
| 본보 10수 뒤   | `[복기](#go/selector/review?turn=10)`             |

그룹·분기 ID는 ASCII 영문·숫자·`_`·`-`로 1–40자이며 해당 답변 안에서만 유효합니다. 전체 UI에서 한 그룹만 활성화되고 같은 선택기를 다시 누르면 꺼집니다. 그룹 없는 좌표는 독립적입니다. `branch`와 `turn`은 함께 쓸 수 없고 `ply`는 `branch`에만 쓰며 기본 0입니다. `turn=0`은 원래 초기 국면입니다. GTP 좌표는 I를 건너뛰고 판 밖은 강조하지 않으며 빈 라벨은 좌표를 표시합니다.

표시는 스크롤 영역에 보이는 Agent 본문에만 적용하며 바둑판도 해당 메시지·선택기의 국면과 같아야 합니다. 도구 기록, 사용자 질문, 접힌 패널에는 적용하지 않습니다. 글자나 판의 좌표에 가까울수록 강조가 진해집니다. 양 끝 호버 또는 글자의 키보드 포커스로 반투명 점선 베지어 곡선을 표시합니다. 판 표시의 오른쪽 위에서 보이는 글자의 왼쪽 위로 연결하고 제어점은 수평 오른쪽·왼쪽으로 뻗습니다. 같은 좌표는 표시를 공유하며 가장 가까운 가시 글자가 밝기·연결을 결정합니다.

## Agent의 시험 진행 편집

`edit_trial`은 서버 `shared/`에서 전체 수순을 검증합니다. 성공하면 도구 이벤트로 현재 답변의 `trials`에 저장하고 대화와 함께 영구 저장합니다. 실패해도 기존 분기는 유지합니다. 생성만으로 판을 이동하거나 실전 기보를 바꾸지 않습니다. 사용자가 selector로 열고 시간축으로 복기·수동 진행·새 대국 저장을 합니다. 선택기를 끄면 강조만 꺼지고 판 위치는 남습니다.

```json
{"id":"line-a","base":"current","moves":["C2","B2"]}
{"id":"line-b","base":"branch","source":"line-a","ply":1,"moves":["B3"]}
```

- `base=current`: 표시된 사용자 시험 진행을 포함한 현재 국면에서 시작.
- `base=main`과 `turn`: 원래 대국의 지정 수 뒤에서 시작.
- `base=branch`와 `source`: 이번 요청에서 만든 분기 사용. `ply`만큼 남기고 `moves`로 나머지를 교체하며 생략하면 덧붙입니다. 같은 `id`는 편집, 새 ID는 새 변화, `moves=[]`는 잘라내기입니다.
- `operation=delete`와 `id`: 이번 분기를 삭제하며 이전 selector는 분기가 없음을 알립니다.

다른 요청에서 편집하려면 먼저 기존 분기·수 번호를 선택하고 질문하여 새 요청의 `current`로 이어갑니다. `source`는 이번 요청의 분기만 조회하며 다른 대화의 같은 ID를 암묵적으로 찾지 않습니다. 분기는 초기 판과 원래 시작점을 저장해 사용자 시험 접두 수순을 복원합니다. 원래 기보가 바뀌어 일치하지 않으면 이동을 거부합니다.

합법적 수순이 엔진 추천을 뜻하지는 않습니다. 전술 판단에는 실제 판·엔진 근거가 필요합니다. 실행 코치 규범의 유일한 출처는 [prompts/coach.zh-CN.md](../../prompts/coach.zh-CN.md)입니다.
