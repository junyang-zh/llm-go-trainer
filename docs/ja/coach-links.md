グループ・分岐 ID は英数字・`_`・`-` の 1〜40 文字で、その回答内の名前空間です。画面全体で有効グループは 1 つ、同じ切り替えを再度押すと解除します。グループなしの点は独立です。`branch` と `turn` は併用不可、`ply` は `branch` とだけ使い、既定 0。`turn=0` は初期局面です。GTP 座標は I を飛ばし、盤外は強調しません。空ラベルは座標を表示します。

マーカーはスクロール領域内に見える Agent 本文にのみ付き、盤面もそのメッセージ・切り替えの局面と一致する必要があります。ツール記録、利用者の質問、折りたたみには付きません。文字または盤上点への距離で強調が変わり、ホバーまたは文字のキーボードフォーカスで半透明の破線ベジェ曲線を表示します。盤上点の右上から可視文字の左上につなぎ、制御点は水平に右・左へ伸びます。同一座標はマーカーを共有し、最も近い可視文字が明るさと線を決めます。

## Agent による試し打ち編集

`edit_trial` はサーバーの `shared/` で全手順を検証し、成功時にツールイベントで回答の `trials` に保存、会話と永続化します。失敗時は既存分岐を保持します。作成だけでは盤面を移動せず実戦も変えません。利用者が selector を押して開き、時間軸で戻る、手動で続ける、新しい棋譜として保存できます。切り替えを閉じても強調が消えるだけで盤面位置は残ります。

```json
{"id":"line-a","base":"current","moves":["C2","B2"]}
{"id":"line-b","base":"branch","source":"line-a","ply":1,"moves":["B3"]}
```

- `base=current`：表示中の利用者の試し打ちを含む現在局面から。
- `base=main` と `turn`：元の対局の指定手数から。
- `base=branch` と `source`：今回作成した分岐から。`ply` 手を残して `moves` で残りを置換し、省略時は追加します。同じ `id` で編集、別 ID で別変化、`moves=[]` で切り詰めます。
- `operation=delete` と `id`：今回の分岐を削除し、既出の selector は存在しない旨を表示します。

別の質問で編集するには既存分岐と手数を先に選び、次の質問の `current` から続けます。`source` は今回の分岐だけを検索し、別会話の同名 ID を暗黙に参照しません。分岐は初期盤面と元の起点を保存して試し打ちの前半を再現し、元の棋譜が変わり一致しない場合は移動を拒否します。

合法手順はエンジン推奨を意味しません。戦術判断には実盤面・エンジンの根拠が必要です。実行時規範の唯一の出典は [prompts/coach.zh-CN.md](../../prompts/coach.zh-CN.md) です。
