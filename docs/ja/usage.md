## インストールと初回起動

[GitHub Releases](https://github.com/junyang-zh/llm-go-trainer/releases) から、Windows 10/11 x64 は `.exe`、macOS 15+ Apple Silicon は `.dmg` を選びます。Windows はインストーラーを実行し、macOS はアプリを Applications にドラッグしてください。`.zip` / `.yml` は自動更新用です。Source code はソースコードであり、インストーラーではありません。

通常版はエンジン・依存ライブラリ・主モデル・HumanSL を同梱し、これらをオフラインで準備できます。`minimal` 版は自動ダウンロードせず、右上の案内に従い左上の「設定 → 囲碁モデル」で「KataGo をダウンロードして有効化」を押して導入しますが、機能は同じです。Windows 通常版は OpenCL を同梱しますが GPU の OpenCL ドライバーが必要です。macOS は Metal とライブラリを同梱し、Homebrew は不要です。macOS は公開用認証情報が揃っている場合に Developer ID 署名と Apple 公証を行い、それ以外は未署名・未公証です。Windows のコード署名は未設定です。

通常版の起動時、または minimal 版で手動導入を開始した後、エンジン・モデルの準備と GPU 初期化がバックグラウンドで進みます。「設定 → 囲碁モデル」で進捗を確認できます。その間も着手、SGF 読み込み、検討が可能です。準備完了後に分析と AI 対局が利用でき、以後は検証済みキャッシュを再利用します。モデル選択・再試行・バックエンドは[エンジンとモデル](engines.md)を参照してください。

「設定 → LLM 接続」でコーチを設定します。モデルと推論の深さは次回以降に保存されます。[LLM 設定](llm.md)、ソースからの実行は[開発ガイド](development.md)をご覧ください。

## 言語

「設定 → 一般 → 言語」で英語、簡体字中国語、繁体字中国語、日本語、韓国語を選べます。既定ではシステム言語に従い、未対応の言語は英語になります。選択はローカルに保存され、盤面・会話・下書きをリセットせず即時反映されます。既知のエンジン通知、モデル状態、エラーも切り替わります。利用者が付けた名前、棋譜、独自モデル名、未知のプロバイダー診断は原文を保持します。この設定は UI 用であり、中国語の実行時コーチプロンプトや生成される回答の言語は自動変更しません。

## 現在の機能

| 項目         | 対応内容                                                                                |
| ------------ | --------------------------------------------------------------------------------------- |
| 盤面         | 9・13・19 路、取り、自殺手禁止、コウ、自由検討、パス、本譜移動                          |
| AI 対局      | KataGo JSONL、黒白選択、置き石なしまたは 2〜9 子、コミ設定                              |
| 難易度       | HumanSL 段級位サンプリング、モデルなし時は損失目数制限のランダム選択、最強モード        |
| 棋風         | ランダム性と損失上限。積極性は接触戦の好みの近似で、ランダムモードのみ                  |
| 分析         | 黒の勝率・目差グラフ、候補手、主変化の試読、領域予測                                    |
| 計点         | 死に石を手動指定した中国ルールの面積プレビュー、置き石補正を含む                        |
| 棋譜         | 野狐・星陣の標準 SGF、UTF-8 / GB18030、初期配置と本譜、SGF 出力                         |
| コーチ       | Markdown ストリーミング、ツール探索と実行記録、着手・局面・変化の解説、停止、根拠の出力 |
| LLM          | DeepSeek API、Codex CLI、Claude Code CLI                                                |
| デスクトップ | Electron、GitHub Release 更新、macOS の任意署名・公証、Windows NSIS                     |

SGF の読み込みでは、ファイルごとに一つの履歴項目を保存し、棋譜集・全分岐・解説・マークを保持します。項目を開いて分岐を選び、親ノードに戻り、選択した局面をメイン盤面に開けます。ファイルサイズ・ノード数・分岐の深さに読み込み制限はありません。途中の配置・石の削除・手番変更も図に従って扱い、不正な着手にはエラーを表示し、元の棋譜は保持します。日本ルールは対局・エンジン分析に対応しますが、正式な終局計点は未実装です。HumanSL の段級位は野狐・星陣の認定段級位ではありません。プラットフォーム連携、全局の自動 LLM 解説、持ち時間、投了、永続分析キャッシュは未対応です。

モデル管理、Windows OpenCL/CUDA 切り替え、回数・時間による探索制限は[エンジンとモデル](engines.md)を参照してください。

## 対局履歴・試し打ち・会話

対局はローカル履歴に自動保存され、「対局履歴」から選択・SGF 入出力できます。デスクトップは `userData/history`、Web は `.local/history` を使います。`GO_TRAINER_HISTORY_DIR` で書き込み可能な保存先を指定できます。レコード単位のアトミックな JSON 保存で、別途 DB は不要、アプリ本体にも書き込みません。OS の一時ディレクトリは消去される場合があります。

「AI 自動着手」と「AI が白 / 黒」を選択します。オフなら両色を手動で打てます。本譜末尾の着手は実戦に追加し、過去の局面での着手・AI 着手・パスは本譜を変えず試し打ちになります。試し打ちの石には手数が付き、消去または新しい棋譜として保存できます。過去の局面の「新しい対局に分岐」はその局面を別対局として保存し、以後の着手を新しい本譜に追加します。時間軸で試し打ちを振り返れますが、その範囲から離れるか対局を切り替えると未保存の試し打ちは終了します。保存されたコーチ分岐は会話から再び開けます。試し打ち局面にも分析・解説を依頼できます。

会話は対局と独立し、対局・手数の切り替えや読み込み・新規対局でも会話と下書きを維持します。「新しい会話」で別セッションを作り、「会話履歴」で復元します。各質問には対局 ID、本譜手数、時刻、試し打ち手順を記録し、失敗・停止も保存します。再起動後は未完了の分析を中断済みと表示します。

`query_game_history` は対局一覧、または `gameId` と `turn` による棋譜・局面を取得します。現在の文脈には利用者の試し打ちも含みます。履歴照会は現在の会話と独立し、棋譜を変更しません。

## 画面とストリーミング

盤面はウィンドウの残り領域に収まります。ページ全体はスクロールせず、会話と設定が個別にスクロールします。左上のロゴから「一般」「囲碁モデル」「AI 自動着手」「LLM 接続」の設定を開きます。LLM とエンジンの状態は会話上部に並びます。

「目差 / 勝率」は常設で、初期状態は折りたたみです。展開すると手数ごとの 2 本の曲線を表示します。エンジン準備後は `min(訓練 visits, 100)` で現在局面を自動分析し、AI 対局では相手の探索を再利用します。「グラフを補完」は未分析の手を順次処理し、停止できます。前面の分析・AI 着手が優先されます。

数値は常に黒視点です。正の目差は黒、負は白のリードで、エンジンによる推定です。未分析の手は空白、未完了の探索は中抜き点です。点をクリックするとその手数へ移動します。本譜内の検討では既存結果を保ち、棋譜・ルール・コミ・エンジン変更では分離します。曲線は今回の実行中のみ保持し、浅い探索は完了済みの深い探索を上書きしません。

現在値は展開時の見出し右側に表示し、折りたたむと非表示になります。探索数と探索数/秒は分析済み進捗と同じ領域に置きます。計算中も曲線・候補手の領域を確保し、結果表示時の盤面移動を防ぎます。「候補手」は盤上の A/B/C を切り替え、展開パネルには独立した候補一覧があります。

会話は Markdown の見出し、リスト、強調、表、引用、コードに対応し、長い表・コードは個別にスクロールします。外部リンクはシステムブラウザーで開きます。先にエンジンの探索数・黒勝率・目差・主変化を示し、次に LLM の回答を表示します。DeepSeek と Claude Code は逐次本文を返します。Codex の更新単位は CLI に依存し、全文生成後に返す場合もあります。

コーチは連と呼吸点を確認し、指定手順を試して応手を探索できます。「この白石は安全か」などの質問に攻め・守り・手抜きを比較できます。ツール記録を開くと手順・目差・主変化を確認できます。「停止」や接続終了は該当する KataGo、LLM、CLI 子プロセスを取り消します。受信済み本文は未完了として残り、完了した解説のみ次の会話文脈に入ります。試し打ちはその解説に保存され、実戦棋譜は変わりません。

## アプリ更新

「設定 → 一般」でバージョン確認、GitHub Release の確認、自動更新を設定します。自動更新は既定でオフ、有効時は起動時と 4 時間ごとに安定版を確認します。ダウンロード後に「再起動してインストール」を押すと記録を保存し、エンジンを終了して更新します。対局・分析中に自動再起動しません。

検証済みモデルがあればモデル・エンジンを含まない minimal 更新を使い、モデル・バックエンド・調整キャッシュを再利用します。有効モデルがない通常版は通常版を使います。[ビルドとリリース](releases.md#updates)に通路と検証を記載しています。

自動インストールはインストール済みデスクトップ版向けで、macOS は Developer ID 署名が必要です。ソース・ブラウザー版はインストールしません。未署名 macOS は説明と Release へのリンクを表示します。
