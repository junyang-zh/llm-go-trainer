# 交互讲解与试下分支

[English](en/coach-links.md) · [简体中文](coach-links.md) · [繁體中文](zh-TW/coach-links.md) · [日本語](ja/coach-links.md) · [한국어](ko/coach-links.md)

选点扩展使用标准 Markdown 的 fragment 链接，因此支持普通段落、列表、表格和引用，也可使用 Markdown 的引用式链接。代码块与行内代码保留原文，不使用 HTML 或 `---#block…` 分隔符。普通网页链接仍按外链处理，未知 fragment 退化为文字。

| 用途             | 示例                                             |
| ---------------- | ------------------------------------------------ |
| 未分组选点       | `[二路爬](#C2)`                                  |
| 分组选点         | `[打吃](#go/point/B3?group=one)`                 |
| 互斥开关         | `[查看变化](#go/selector/one)`                   |
| 定位试下起点     | `[变化一](#go/selector/one?branch=line-a&ply=0)` |
| 定位试下第二手后 | `[后续](#go/selector/two?branch=line-a&ply=2)`   |
| 定位原局第十手后 | `[回看](#go/selector/review?turn=10)`            |

分组 ID 和分支 ID 使用 1–40 个英文字母、数字、`_` 或 `-`。分组与分支都属于本条回答的命名空间。全界面同一时间只启用一个分组，再点同一个开关关闭高亮；未分组选点不受分组影响。`branch` 与 `turn` 不能同时出现，`ply` 只与 `branch` 搭配，省略时为 0。`turn=0` 为原局初始局面。坐标使用 GTP（跳过 I），超出当前棋盘的坐标不高亮，空标签自动显示坐标。

标记只作用于 Agent 正文。文字须处于对话滚动区域的可视范围，棋盘也须处于该消息或开关定位的局面；工具记录、用户提问、折叠面板不产生标记。鼠标越接近文字或对应棋盘点，高亮越深；悬浮任一端或键盘聚焦文字会显示半透明虚线贝塞尔曲线，从棋盘标记右上缘连接到可见文字左上角，两端控制点分别水平向右、向左延伸。重复坐标共用棋盘标记，鼠标较近的可见文字决定亮度和连线。

## Agent 编辑试下

`edit_trial` 在服务端调用 `shared/` 规则验证整条手顺，成功后通过工具事件保存到当前回答的 `trials`，并随对话持久化。失败保留已有分支。创建分支不会自动切换棋盘，也不会修改实战棋谱；用户点击 selector 后才打开，可用现有时间轴回看、继续手动试下或另存为新棋局。关闭开关只关闭高亮，保留棋盘位置。

```json
{"id":"line-a","base":"current","moves":["C2","B2"]}
{"id":"line-b","base":"branch","source":"line-a","ply":1,"moves":["B3"]}
```

- `base=current`：从用户当前局面开始，包含已显示的用户试下。
- `base=main` 与 `turn`：从原局某手之后开始。
- `base=branch` 与 `source`：从本轮已有分支开始。`ply` 保留前几手，`moves` 替换剩余后续；省略 `ply` 则追加。使用相同 `id` 修改原分支，不同 `id` 建立另一条变化。`moves=[]` 可截断。
- `operation=delete` 与 `id`：删除本轮分支；已输出的旧 selector 会提示分支不存在。

跨轮编辑可先选择已有分支并定位到需要的手数，再提问；新一轮通过 `current` 继续。工具的 `source` 仅查本轮已创建的分支，不跨对话隐式查找同名 ID。分支记录包含起始棋盘和原局起点，用于还原用户试下前缀；原局已改变而不再匹配时拒绝跳转。

合法手顺不代表引擎推荐，战术判断仍需真实棋盘或引擎证据。运行时教练规范的唯一来源为 [prompts/coach.zh-CN.md](../prompts/coach.zh-CN.md)。
